# ⚡ My Personal Terminal Portfolio

Hey! 👋 This is my personal portfolio website. 

Instead of a standard boring website, I decided to build a retro, dark-themed hacker terminal from scratch using **pure HTML, CSS, and Vanilla JavaScript**.

🌐 **Live Site:** https://kartikeynegi25.github.io/personal-site

---

## 🔥 Features I Built

- **Interactive Web Terminal:** Visitors can type real commands directly into the site (try typing `help`, `skills`, `matrix`, `date`, or `sudo`).
- **Retro Keyclick Audio:** Created custom typing and error sound effects directly in JS using the Web Audio API.
- **Matrix Rain Canvas:** A custom HTML5 background effect streaming green code down the screen.
- **CRT Scanline Overlay:** Added a vintage monitor overlay to give it a full retro terminal vibe.
- **Fully Responsive:** Tweaked the layout and CSS so it works smoothly on both phone screens and laptops.

---

## 🛠️ Built With

- **HTML5** (Structure & markup)
- **CSS3** (Styling, animations, and mobile media queries)
- **JavaScript** (Terminal logic, sound generation, and canvas animation)
